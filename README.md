# ASP.NET MVC CRUD

A simple CRUD application built with **ASP.NET Core MVC (.NET 8)**, demonstrating core MVC concepts and common web development practices.

## Features

- Create, read, update, and delete operations
- Server-side rendering with Razor Views
- Form handling and model validation
- Entity Framework Core for data persistence
- Bootstrap for the user interface

## Tech Stack

- C# / .NET 8
- ASP.NET Core MVC
- Razor Views
- Entity Framework Core
- SQL Server
- Bootstrap

## Getting Started

1. Clone the repository.
2. Configure the database connection string.
3. Apply database migrations.
4. Run the application.

```bash
dotnet restore
dotnet ef database update
dotnet run
```
